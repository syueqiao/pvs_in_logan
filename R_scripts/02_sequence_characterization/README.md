Scripts here are used to overall characterize what the sequences from Logan consists of:
- `reclass_viz.R` contains visualization scripts used to generate figures for my reclassification exam :)
- `bugging2.R` is a remnant of when I was trying (and failing) to port everything to Jupyter notebooks
- `hmmer-results.R` used for parsing and understanding Logan outputs once HMMs were run to identify ORFs
- `L1_pathracer_mining.R`, `pathracer_fullness_hmm.R` , `vert_counts.R` and `pilot_pr_test.R` were used for figuring out what I should try to use Pathracer for, and making sense of the outputs.
- `ncbi_L1_character.R` was used for characterizing PV sequences retrieved from NCBI Virus
- `sum_stats_longcontig.R` is mostly rough work trying to figure out what lenghts we were getting, and what needed to be done to get more long sequences.
